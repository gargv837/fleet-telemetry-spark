Fleet Telemetry Aggregator

Live demo of a PySpark batch pipeline that turns partitioned vehicle GPS events into geohash / time-window idle-zone and distance metrics — the same analytical pattern used to keep heavy scans off an OLTP path.

Source code Download sample aggregates (CSV) Raw stats (JSON)

Pipeline

  1. Ingest date-partitioned GPS events (date=YYYY-MM-DD/)
  2. Derive geohash buckets + 1-hour windows; flag idle pings (speed < 3 km/h)
  3. Window-lag distance between consecutive pings per vehicle (shuffle by vehicle_id)
  4. Aggregate idle ratio / distance / speed; write partitioned Parquet

Highest idle-ratio zones ping_count ≥ 5
